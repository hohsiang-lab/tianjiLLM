## Relationships

```
SpendLogs.api_key ──LEFT JOIN──▶ VerificationToken.token
                                  └─▶ key_alias (displayed as "Key Alias" column)

SpendLogs.upstream_token_key ──cross-reference──▶ RateLimitStore token key
                                                   (same SHA256[:12] format)
```

## Data Flow (write path)

```
Native proxy SUCCESS: upstream.APIKey
  → ctx = context.WithValue(ctx, ContextKeyUpstreamToken, sha256(apiKey)[:12])
  → buildBaseLogData(ctx) extracts UpstreamTokenKey
  → callback.LogData.UpstreamTokenKey
  → spend.SpendRecord.UpstreamTokenKey
  → db.CreateSpendLogParams.UpstreamTokenKey
  → SpendLogs.upstream_token_key column

Native proxy FAILURE (non-200):
  → ctx already has ContextKeyUpstreamToken (set before ReverseProxy)
  → InsertErrorLog extracts from ctx:
      UpstreamTokenKey, EndUser, OrganizationID
  → ErrorLogs.upstream_token_key + end_user + organization_id columns
  → Also fills Model from requestModel (was previously empty string)

Standard provider SUCCESS: (context has no ContextKeyUpstreamToken)
  → callback.LogData.UpstreamTokenKey = "" (zero value)
  → SpendLogs.upstream_token_key = '' (DEFAULT)

Standard provider FAILURE:
  → InsertErrorLog: UpstreamTokenKey = "" (context has no token)
  → ErrorLogs.upstream_token_key = ''
```

## Data Flow (read path)

```
ListRequestLogs query:
  SpendLogs LEFT JOIN VerificationToken ON api_key = token
  → row.KeyAlias = COALESCE(vt.key_alias, '')
  → row.UpstreamTokenKey = sl.upstream_token_key

  → handler toLogRow() maps to RequestLogRow{KeyAlias, UpstreamTokenKey}
  → logs.templ renders both columns
```
